# سيرفر نور (Server Noor)

منصة مجانية لمساعدة المبتدئين في إنشاء وإدارة سيرفرات ماين كرافت (Minecraft) على الاستضافات المجانية، بالكامل باللغة العربية، وبالالتزام الكامل بالشريعة الإسلامية.

## فكرة المشروع
كثير من الشباب يريدون تشغيل سيرفر ماين كرافت مع أصدقائهم على استضافات مجانية (مثل Aternos, Minehut)، لكنهم يواجهون صعوبات في الإعداد وحل الأخطاء. منصتنا تربط بين المستخدم واستضافته، وتمنح المنصة صلاحيات محدودة على السيرفر، ثم يستطيع المستخدم التحدث مع مساعد ذكي بالعربية لتنفيذ أوامره على السيرفر (تثبيت إضافات، إعادة تشغيل، حل مشاكل، إلخ).

## التكلفة
صفر تكلفة تشغيل. نعتمد بشكل كامل على:
- **GitHub Pages** لاستضافة الموقع
- **GitHub Actions** للنشر التلقائي (CI/CD)
- **GitHub API** للتفاعل مع البيانات
- **GitHub Issues** لتذاكر الدعم

## التقنيات المستخدمة
- HTML5 + Tailwind CSS (via CDN)
- JavaScript (Vanilla)
- GitHub Pages
- GitHub Actions

## الالتزام بالشريعة الإسلامية
- جميع الخدمات مجانية (لا ربا، لا رسوم خفية).
- لا contenن أي عناصر قمار أو رهان.
- شفافية كاملة في الشروط والسياسات.
- أمان وحماية لبيانات المستخدمين.
- لا نسمح بمحتوى محرم أو مخالف للشريعة.

## كيفية البدء
1. استنسخ المستودع:
   ```bash
   git clone https://github.com/USERNAME/server-noor.git
   ```
2. افتح `index.html` في المتصفح.
3. للتطوير، تعدل على ملفات `css/` و `js/` ثم أرسل Pull Request.
